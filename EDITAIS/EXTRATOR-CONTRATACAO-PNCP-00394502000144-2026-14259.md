# Extrator exclusivo — contratação PNCP 00394502000144/2026/14259

**Fonte indicada:** https://pncp.gov.br/app/editais/00394502000144/2026/14259

Este script foi criado especificamente para uma contratação individual. Extrai os dados gerais, itens, histórico/eventos e respostas brutas da API pública do PNCP; organiza os resultados em CSV e em uma planilha Excel com abas **Dados gerais**, **Itens**, **Histórico** e **Metadados**.

## Arquivos de saída
O diretório padrão é `EDITAIS/CONTRATACAO-00394502000144-2026-14259/`:
- `contratacao-completa.xlsx`
- `contratacao-geral.csv`
- `itens.csv`
- `historico.csv`
- `contratacao-geral.json`
- `itens.json`
- `eventos.json`
- `metadados.json`

## Execução
```bash
python -m pip install requests openpyxl
python scripts/capture_pncp_contratacao.py
```

Para outra contratação com o mesmo formato de URL:
```bash
python scripts/capture_pncp_contratacao.py --url "https://pncp.gov.br/app/editais/CNPJ/ANO/SEQUENCIAL"
```

## Critério de integridade
O script grava apenas dados retornados pela API. Se um endpoint falhar, registra o erro e marca a extração como parcial ou falha; campos ausentes ficam vazios, sem preencher valores com base em suposições. A execução deve ser validada contra a página pública caso o esquema do PNCP mude.
