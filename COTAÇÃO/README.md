# COTAÇÃO

Pasta destinada à organização de cotações relacionadas às oportunidades de licitação do projeto LICITACAO.

Registre, para cada cotação, a fonte, o fornecedor, a data de consulta, a validade, os itens, os preços, frete, tributos, prazo de entrega e condições comerciais. Preserve links e evidências de origem. Não considere valores como atuais sem reconfirmação junto ao fornecedor.
