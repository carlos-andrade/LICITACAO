# Fornecedores

Pasta destinada ao registo organizado de fornecedores relacionados com processos de contratação pública tratados no projeto LICITACAO.

## Estrutura prevista

Cada fornecedor poderá ter uma ficha própria, com informação verificável e fonte identificada. Conforme aplicável, a ficha deve distinguir:

- **Identificação:** razão social, CNPJ e dados cadastrais públicos;
- **Contacto institucional:** canais publicados oficialmente;
- **Área de fornecimento:** categorias de bens ou serviços;
- **Fontes e evidências:** URLs, documentos consultados e data de consulta;
- **Verificações:** situação cadastral e outras consultas relevantes, com a respetiva data;
- **Histórico:** alterações documentadas e vínculo a editais/processos relevantes.

## Regras de registo

1. Não inserir informação sem fonte ou apresentá-la como confirmada sem verificação.
2. Registar datas de consulta para dados sujeitos a alteração.
3. Distinguir dados declarados pelo fornecedor de dados verificados em fontes oficiais.
4. Não guardar palavras-passe, credenciais, dados pessoais desnecessários ou informação comercial confidencial sem autorização e necessidade documentada.
5. Manter os documentos originais e a rastreabilidade das alterações.
