# IMPRESSÃO — LICITAÇÃO

Pasta destinada aos documentos preparados para impressão, com controle de versão e cabeçalho documental conforme a norma do projeto.

## Regras de utilização

- Guardar aqui somente versões finais ou expressamente preparadas para impressão.
- Manter os documentos-fonte nas suas pastas funcionais originais.
- Identificar versão, estado e origem de cada arquivo.
- Não considerar um documento aprovado sem evidência formal de aprovação.
