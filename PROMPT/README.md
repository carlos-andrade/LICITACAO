# PROMPT

Pasta destinada a organizar prompts utilizados no projeto LICITACAO.

Para cada prompt, registre seu objetivo, contexto de uso, entradas esperadas, formato de saída e limitações relevantes. Evite incluir senhas, tokens, chaves de API, dados pessoais desnecessários ou outras informações confidenciais.

Quando um prompt apoiar análises de editais, cotações ou orçamentos, preserve a rastreabilidade das fontes e diferencie fatos documentados de hipóteses e estimativas.
